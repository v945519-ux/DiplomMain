# Пиццерия Ронни — фон, шапка и фотографии

- Белый фон, небольшие статичные облака через CSS. Нет постоянных анимаций, backdrop-filter или blur; декоративные облака скрыты на телефоне.
- Белая sticky-шапка с мягкими скруглениями и общим стилем навигации.
- Название «Пиццерия Ронни» заменено в шапках, подвале, главной странице, форме входа и metadata.
- Все 99 доступных товаров сохранены. Файлы фотографий всех товаров присутствуют.
- Устранён лишний путь загрузки существующих фото через Django: каталог использует локальные WebP-копии, созданные из оригиналов в config/media/products. 116 файлов (включая неиспользуемые сейчас): 59 347 030 байт → 3 794 822 байта. Новые фото, которых ещё нет в карте, продолжают загружаться через API.
- Картинки ниже первого экрана остаются lazy-loaded. В каталоге, корзине и странице товара готовые WebP передаются без повторной серверной оптимизации.

После замены исходных изображений выполните из client:

```
node scripts/sync-catalog-images.cjs
npm run build
```

Зависимости не добавлялись: использован уже установленный sharp. База данных и исходные фото не менялись.

Проверки результата и скриншоты: ronni-result.json, ronni-desktop.png, ronni-mobile.png. Браузерная проверка ronni-live.cjs использует настоящий Django API и прокручивает весь каталог, проверяя декодирование всех 99 фото.
